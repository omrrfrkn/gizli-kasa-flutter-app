📦 Gizli Kasa Flutter Uygulaması

Bu proje Flutter kullanılarak geliştirilmiş bir gizli kasa uygulamasıdır. Kullanıcıların kişisel notlarını ve verilerini güvenli bir şekilde saklamasını amaçlar.

🚀 Özellikler
🔐 Güvenli veri saklama
📝 Not ekleme ve silme
📱 Mobil uyumlu arayüz
⚡ Hızlı ve basit kullanım
🛠️ Kullanılan Teknolojiler
Flutter
Dart
Android / iOS / Web desteği
📂 Proje Yapısı
lib/ → Ana kodlar
android/ → Android platform dosyaları
ios/ → iOS platform dosyaları
▶️ Kurulum
git clone https://github.com/omrrfrkn/gizli-kasa-flutter-app.git
cd gizli-kasa-flutter-app
flutter pub get
flutter run
